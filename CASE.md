# «Злой инвестор»: конкурсная версия

Основной сценарий: главная / → режим и инвестор → стадия и питч → пять вопросов → десять оценок с цитатами или отсутствием данных → ровно три действия → реванш с прежним инвестором. /prototype/ — сохранённый альтернативный React UI того же API, подписанный на главной.

Конкурсный режим фиксирует Хартманна; расширенный допускает выбор из пяти профилей до начала. Серверные раунды сохраняют personaId и mode; ответы и реванш не меняют их. Старые сохранённые раунды без personaId используют профиль по умолчанию. Stateless-режим доверяет истории клиента, поэтому не является защищённым конкурсным протоколом аттестации.

Персонажи в lib/personas.js содержат приоритеты, стиль, сомнения, вопросы, рекомендации, источники и явное отделение интерпретации от документированных принципов. Это не реальные люди и не их представители. Источники: публичные интервью и собственные материалы; ссылки доступны в интерфейсе. Персонализация не меняет арифметику и рубрику.

lib/round.js сохраняет DeepSeek, обработку ошибок и проверку JSON. Каждый запрос содержит выбранный профиль, весь питч, историю, анкету и обновлённый анализ из lib/analysis.js. Семантические находки модели принимаются только с точными цитатами. Отсутствие ключа включает общий rules-движок lib/interview.js + lib/structured-round.js; локальный React mock явно включается отдельно. Реальная доступность и качество DeepSeek без ключа не подтверждены.

Общие критерии из задания команды — lib/rubric.js. Шкала 0/1/2/null является шкалой тренажёра, не объявляется официальной. Факт оплаты или артефакта со слов автора не считается независимо проверенным. Для стадии идеи отсутствие продаж/регистрации не является приговором всей идее.

Сохранены Node API, главная с дизайном команды, React, SQLite/Redis-сессии, идемпотентность отправки, реванш, сравнение и Jev. Новых зависимостей для анализа не добавлено.

Готовность проверяется npm run check, npm test, npm run build и прохождением браузерного сценария. Тесты DeepSeek подменяют HTTP, а не доказывают реальную генерацию. Арифметика покрывает только явно подписанные величины одинаковой валюты и периода в одном предложении. Не реализованы независимый фактчекинг, универсальная финансовая модель и полная защита от манипуляций. Условия деплоя и one-pager находятся в README.
